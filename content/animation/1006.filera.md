## Hey, this is Filera

I built Filera because renaming a lot of files shouldn’t require writing a script or wrestling with regular expressions. Stack a few simple tasks, see the results immediately, and rename everything when it looks right.

Filera is new, open source, and ready to try on macOS, Windows, and Linux. **[Go download it and give it a spin](https://filera.app/docs/getting-started/installation).**

## Build a rename, not a script

Drop in some files—or a whole folder—and build your rename from simple steps like find and replace, numbering, custom text, case changes, and dates.

The original and new names sit side by side, so you always know what’s happening. Filters let you target files by name, extension, date, or size.

## Check your work first

Filera doesn’t touch your files while you’re setting things up. It previews every change, shows which files are filtered out, and catches duplicate names before you run anything.

When you’re ready, you can rename files in place, copy them, or move and rename them at the same time.

## Under the hood

Filera is built with Tauri, Vue, TypeScript, and Rust. The interface handles the live preview, while Rust takes care of the filesystem work.

GitHub Actions builds releases for macOS, Windows, Linux, and NixOS—including signing and notarizing the macOS app.

## Docs, too

I also built [filera.app](https://filera.app), with guides for installing Filera and using every task, filter, and output mode.
